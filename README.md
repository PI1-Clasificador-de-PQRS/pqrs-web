# pqrs-web

Dashboard del MVP del Clasificador automático de PQRS (Proyecto Integrador I, Universidad de
Antioquia). Next.js (App Router) con un proxy BFF hacia `pqrs-api`.

> Documentación completa en construcción (E3).

## Comandos

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm gen:api      # regenera src/lib/api/schema.d.ts desde openapi/openapi.json
```
